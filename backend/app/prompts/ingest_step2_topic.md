# Step2c:单主题深度页生成

为下面这一个主题生成一份**深度、完整、详尽**的 wiki 主题页。目标长度 1200-3000 字,**每段都要写满,不要省略**。

## 输入

### 当前主题(Step1 抽取结果)

```json
{topic_json}
```

### 原始素材全文

```
{raw_md}
```

### 来源素材 slug

`{source_slug}`

### Step1 抽取的全部实体名(供你引用 [[X]],只用名字)

{entity_names_block}

### 现有相关 wiki 页(若存在,只读)

{related_pages_block}

## 输出要求(单页 markdown,含 frontmatter)

直接输出页面 markdown 全文,不要任何分隔符、不要前后解释文字。

### frontmatter

```yaml
---
title: <主题名>
slug: <主题名>
kind: topic
tags: []
domains: <来自 step1 主题或源 domain_tags>
sources: ["{source_slug}"]
related_entities: <来自 step1.topic.related_entities>
version: 1
---
```

### body 强制 8 段骨架

#### `## 主题概要`

200-400 字概述本主题的边界、核心问题、研究意义。引用原文证据(`> 引自来源:[[{source_slug}]]:...`)。

#### `## 关键实体`

列出 step1.topic.related_entities 中的所有实体,**每条 ≥40 字**,说明该实体在本主题下的角色/作用。

```
- [[{entity1}]]:在本主题中扮演 ...,负责 ...
- [[{entity2}]]:...
```

至少 3 条;有多少写多少。

#### `## 核心论点`

把 step1.topic.key_points 展开,每条扩成 ≥80 字的论述段,引用原文。最少 3 条,丰富时给到 8 条。

#### `## 主题脉络`

200-400 字,描述本主题在原文中的逻辑展开顺序、章节结构、内在联系。

#### `## 不同来源的视角 / ### 来源:[[{source_slug}]]`

100-300 字,本素材在本主题下的独特视角、独特观点。其他素材入库后会在同一 H2 下追加新的 H3 子段。

#### `## 尚待解决的问题`

如果原文中暗示了开放问题/未解之谜/未来研究方向,逐条列出,每条 ≥30 字。原文未涉及时写"(本素材未提及尚待解决的问题)"。**这一段会被 followups 队列抽取**,务必规整。

#### `## 相关主题`

逐条列举与本主题相邻的其他主题,每条 ≥40 字阐述关联。

**双链白名单铁律**:本段提到的相邻主题名**不在任何给定清单内**,因此**一律只写纯文本、绝不加 `[[ ]]`**(例:写 `精益生产`,不要写 `[[精益生产]]`)。只有「可引用实体白名单」(上面 `{entity_names_block}` 列出的实体名)里逐字出现的名字才允许写成 `[[X]]` 双链。

```
- 相关主题 1:与本主题在 ... 维度上相邻,区别在于 ...
```

#### `## 参考来源`

```
- [[{source_slug}]]
```

## 引用规范

- **双链白名单铁律(全文通用)**:`[[X]]` 里的 X **必须逐字来自「可引用实体白名单」(`{entity_names_block}`)或本来源 slug(`{source_slug}`)**。白名单外的任何概念/主题,**只写纯文本、绝不加 `[[ ]]`**。违反会产生虚空链接。
- **引用格式铁律**:每条 `> 引自来源:[[{source_slug}]]:...` **必须独占一行、行首顶格写 `>`**,绝不能接在正文句尾(如 `…结束。 > 引自来源` 是错的);引用块与上方正文之间、多条引用之间都**必须空一行**;source 名**必须用 `[[ ]]` 双链**,不能写裸 slug。
- 关系类型注释(可选):注释必须写在 `]]` **之后**,绝不能写进 `[[...]]` 内部。
  - 正确:`[[工业工程]] <!-- type: 相关 --> <!-- confidence: EXTRACTED -->`
  - 错误:`[[工业工程<!-- type: 相关 -->]]`(注释写进双链内部,会导致链接失效)
  - 双链 `[[X]]` 里只能是页面名本身,不能含任何 `<!-- -->` 注释、空格说明或标点。
