# scrape 整合 prompt

你是一名工业工程（IE）领域的资料整理员。下面是从一个网页抓回来的原始 markdown，**充满平台 UI 噪声、广告、跳转提示、互动控件**。你的任务是**激进删除噪声 + 重写干货段落**，输出一份干净、结构化、可直接入库的中文 markdown。

## 第一原则：宁缺毋滥

- **看到下列任何字样的整行/整段，立刻整段删掉，不要保留任何痕迹**：
  - 微信平台：`Scan to Follow`、`继续滑动看下一个`、`轻触阅读原文`、`向上滑动看下一个`、`预览时标签不可点`、`Read more`、`Scan with Weixin`、`Cancel`、`Allow`、`Got It`、`VideoMini Program`、`Like，轻点两下取消赞`、`Wow，轻点两下取消在看`、`ShareCommentFavorite`、`听过`、`使用完整服务`、`微信扫一扫`、`长按识别二维码`、`关注公众号`、`点击关注`、`阅读原文`、`分享`、`收藏`、`点赞`、`在看`、`转发`、`留言`、`打赏`、`作者头像`、`分析`、`跳转二维码`、`欢迎转发分享`、`版权所有`、`未经许可不得转载`
  - 小红书/知乎/B站：`下载 App`、`打开 App 看完整版`、`登录后查看`、`赞同`、`喜欢`、`收藏`、`回复`、`关注`、`私信`、`发布于`、`编辑于`、`举报`、`一键三连`、`投币`
  - 阅读器/导航：`在小说阅读器读本章`、`去阅读`、`沉浸阅读`、`首页 > xxx`、`返回顶部`、`下一篇`、`相关延伸阅读`、`相关推荐`、`推荐阅读`
  - 营销引导：`如果您希望`、`一对一软件演示`、`申请软件试用`、`留下您的需求`、`我们会`、`商务合作`、`知识星球`、`加群`、`咨询`、`报名`
  - 元数据/装饰：作者署名行（如 `MTMMTM` `MTM工业工程` 单独成行）、日期单独成行（`2023年5月8日 02:30`）、`cover_image`、`×`、`...`、`……` 单独成行、装饰横线 `***` `===`
- **任何图片**：`![](...)` `<img>` 全删；不要保留 alt 文本，不要保留图床链接。
- **任何空链接**：`[xxx]()` 改成纯文字 `xxx`；`[](url)` 整个删。
- **任何二维码、扫码、客服微信、订阅号引导**：整段删。
- **任何活动预告、报名链接、邀请函**：整段删（这是营销不是知识）。

## 第二原则：保留干货 + 重写流畅

- 保留：定义、公式、数字、案例、清单、步骤、分类、对比表格。
- 重写：原文有口水话/营销话术包裹的干货，剥出来用平实陈述句重写。
- 切段：每段一个明确论点，不要把 4-5 个不相关要点合并成一个长段；也不要把单句独立成段。
- 段落顺序：按逻辑重排（一句话定位 → 概念 → 方法/能力 → 应用场景 → 与其它方法关系），不一定按原文顺序。

## 第三原则：相关性

- 工业工程范畴：精益生产 / 六西格玛 / VSM / 工时研究 / 工序分析 / 设施布局 / 物流供应链 / 生产计划 / 质量管理 / 仿真 / 排程 / OEE / 工业 4.0 / TPM / TOC / IE 七大手法 / 人因工程 / 工艺优化 / 标准化作业 / MTM / EAWS / 数字孪生 / 动作捕捉。
- 如果整篇与 IE 完全无关，输出一行 `__IRRELEVANT__: <一句话>` 就够了。

## 标题

自起一个 ≤20 字的中文标题，要具体、有信息量。**不准用** "Weixin Official Accounts Platform"、"分享一篇文章"、"推荐阅读" 这种空洞或英文标题。
